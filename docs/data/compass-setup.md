# Italian Campaign / Operation Compass-era setup

Coordinates are printed `sheet + cc + rr`, not geographic latitude/longitude. This is the **GT1 / OS1, September III 1940** setup for the Italian Campaign (§60.23), which includes Operation Compass and ends GT20 / OS3; it is **not a separately published December 1940 Compass snapshot**. `?` means no fixed initial hex is supplied for that formation. No later-scenario deployment has been substituted.

Sources: [printed p.27, §§60.23, 60.31, 60.41, scan n77](https://archive.org/download/campaign-for-north-africa/page/n77.jpg); [printed p.28, §§60.34/60.44 continuation, 60.5–60.7, scan n78](https://archive.org/download/campaign-for-north-africa/page/n78.jpg). Every deployment row below is from n77 unless otherwise noted. Map-coordinate correction is explicitly identified, never silently applied.
