# Close-assault Combat Results Table (§15.79)

Sources: [published chart, scan n98](https://archive.org/download/campaign-for-north-africa/page/n98.jpg); [rulebook OCR, §§11.2, 15.3–15.9](https://archive.org/download/campaign-for-north-africa/The%20Campaign%20for%20North%20Africa_djvu.txt).

## Encoding

- All ranges are inclusive. `-` means no result in that row, not an unreadable value.
- Loss rolls are two distinguishable d6 read sequentially, physically larger die first (not the higher face first). The possible rolls are 11–16, 21–26, 31–36, 41–46, 51–56, 61–66. Numeric range endpoints are transcribed exactly even when an endpoint is not a possible dice result.
- Capture, Engaged, and retreat use the sum of the same two dice (2–12), not the sequential roll.
- Printed anomaly retained: attacker differential −2, 20% row is `13-18` in the scan. It is not silently corrected to `13-16`; both encompass the same attainable sequential rolls.
- There are no unreadable cells. Overrun comprises +11..+13, +14..+16, and ≥+17.

### Application rules (§§15.73–15.88)

- Each side rolls its own pair once and uses its own loss panel at the shared differential.
- Retreat overrides Engaged. Zero losses do not prevent either result. Attackers never undergo involuntary retreat.
- Defender retreat distance is the listed minimum. Each required hex not retreated adds 10% loss. Units in major cities, including units retreating into them, may ignore remaining retreat.
- Capture sum triggers a further single-die roll on §15.89 to determine the captured fraction of the losses; it is not a fraction of the original force.
- Overrun defender losses round upward. Losses of at least 30% inflict 3 Disorganization Points on all involved units of that side.

## Modifiers and CP costs

The CRT image itself contains no modifier list. The following numeric modifiers are from the surrounding rules; terrain entries below are those explicitly quantified in §15.3, not a substitute for the separate complete §8.37 terrain chart. Positive column shifts favor the attacker; negative shifts favor the defender. Strength reductions are not column shifts.

### Terrain (§15.3)

| Condition | Attacker column shift | Rule |
|---|---:|---|
| Clear hex | 0 | 15.32 |
| Sand/gravel hex | 0 | 15.32 |
| Mountain hex | -3 | 15.32 |
| Salt marsh hex | +1 | 15.32 |
| Wadi hexside | -1 | 15.33 |
| Rough hex | -2 | 15.35 example |
| Level 2 fortification | -2 | 15.35 example |
| Ridge hexside | -2 | 15.35 example |
| Down-slope hexside | +1 | 15.36 |
| Up-escarpment hexside | -3 | 15.36 |

Terrain modifiers accumulate. Only one defending hexside terrain benefit applies unless an actually assaulted hexside contains two terrain types. Any attacker crossing a qualifying hexside activates its modifier. Upward and downward benefits offset. Motorized units cannot assault up an escarpment (even along a track) or assault salt-marsh defenders.
