## Morale-to-close-assault column shift (§15.61-15.62)

| Adjusted attacker morale minus adjusted defender morale | Signed column shift (right positive) |
|---|---|
| Positive n | +n |
| 0 | 0 |
| Negative n | n |

Source page image: https://archive.org/download/campaign-for-north-africa/page/n23.jpg

The shift is the morale difference itself, not a separate banded lookup. Morale-table modifiers adjust basic morale before this subtraction. Positive shifts favor the attacker; negative shifts favor the defender.
