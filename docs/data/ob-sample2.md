# Additional named CNA counters

Mechanics-only continuation of [ob-sample.md](ob-sample.md). Existing 409 rows are not re-derived. This extension records additional named land counters, including named support identities visible on countersheet reproductions. It is not a claim that every physical marker is a combat unit or that all units coexist on-map.

## Reading the tables

- One row is one named counter. Replacement/redesignation HQ counters are identified as such rather than treated as an additional simultaneous formation. The two LRDG counters are separate physical identities.
- `—` means printed not applicable/no separate rating; `?` means unreadable or no published join located. Unknown is not zero.
- TOE is arrival strength. OA `N` is expanded to the ID profile maximum; understrength/overstrength numbers remain the printed actual values. HQ profiles without TOE retain `—`.
- Offensive/defensive assault, barrage, anti-armor, AA, armor and weapon CPA are per TOE point. Semicolon vectors follow weapon component order. Ratings are not multiplied by TOE or combined into an invented counter strength. Parentheses and CPA `*`/`+` retain published qualifiers.
- Morale columns distinguish basic and parenthesized arrival morale. Commonwealth profiles: [n166](https://archive.org/download/campaign-for-north-africa/page/n166.jpg), [n167](https://archive.org/download/campaign-for-north-africa/page/n167.jpg). Weapon profiles: [n178](https://archive.org/download/campaign-for-north-africa/page/n178.jpg). The page image, not garbled OCR, determines the transcribed value.
- Weapon abbreviations: pdr = pounder; how = howitzer; gun = gun; SP = self-propelled; Crusader I/II = Crusader Mk I/II; Matilda = Matilda Mk II; Valentine = Valentine Mk II; Stuart = Stuart M3; Grant = Grant M3; A9/A10/A13 = Cruiser; Light AA = Bofors 40mm; Heavy AA = 3.7-inch.
- Reinforcement cross-check: [n113](https://archive.org/download/campaign-for-north-africa/page/n113.jpg), [n114](https://archive.org/download/campaign-for-north-africa/page/n114.jpg). These tables do not infer calendar dates or scenario participation from arrival.

A final separately labeled rename row records an OA-note identity without asserting a second physical counter. `N` is expanded to profile maximum; `U@`/`O@` use the actual published strength. `—` is printed not applicable, `?` means unknown/no exact join. For weapon-bearing units ratings are per component TOE point, with semicolon vectors matching weapons exactly. Profile and weapon CPA are separate. Morale is basic morale; these German OA groups do not print a separate arrival morale. HQs with no TOE have `—`, not zero. Engineers retain the profile's `(1)` maximum notation.

Thus neither adds German combat rows. Generic Eng/Depl, POW, prison-guard and reserve markers are not German named unit identities.

`†` fixes HQ CPA independently of assigned weapon CPA; `+` denotes historical motorization. `‡` armor 1 for ID j applies only while truck/motorization-transported (halftracks); otherwise armor is —. `**` fixes ID z CPA independently of assigned weapon CPA.
