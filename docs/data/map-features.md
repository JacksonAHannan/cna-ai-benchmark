# Named CNA map features

`sheet + cc + rr` reproduces the printed four-digit map coordinate. Leading zeroes are significant. A repeated name denotes another occupied hex or another feature type, not another settlement. `?` means the coordinate or exact feature classification could not be read confidently; it does not mean the feature is absent. No coordinate is estimated from a label's geographical position.

Primary images: [A, n187](https://archive.org/download/campaign-for-north-africa/page/n187.jpg), [B, n188](https://archive.org/download/campaign-for-north-africa/page/n188.jpg), [C, n189](https://archive.org/download/campaign-for-north-africa/page/n189.jpg), [D, n190](https://archive.org/download/campaign-for-north-africa/page/n190.jpg), [E, n191](https://archive.org/download/campaign-for-north-africa/page/n191.jpg). Images were also inspected in enlarged crops; clockwise rotation does not alter the printed coordinates. The **Summary of Important Locations on sheet A** supplies authoritative coordinates for its indexed names, including names on B–E. All mainland coordinates below are original-board coordinates, not a conversion from the Vassal image. Sheet membership at overlaps is therefore the printed sheet identifier, not an inferred polygon membership.

Port notes give **maximum efficiency; supply tons per Operations Stage**, from [§55.3 chart, n109](https://archive.org/download/campaign-for-north-africa/page/n109.jpg). The `other ports` category is efficiency 1; 100 tons. Tripoli and Bizerta are off-map destinations, not fabricated map hexes. Air facilities are separately cross-indexed against [§60.5, printed p.28, n78](https://archive.org/download/campaign-for-north-africa/page/n78.jpg); that setup list is distinguished from the map's settlement symbol.

## Limits and conflicts

- This inventory includes the named settlement, oasis, air-facility and fort labels readable in the scans, plus the printed important-location index and scenario facility cross-index. Small labels/dots that could not be confidently associated with a printed number remain `?`; unnamed terrain, wadis and generic air/fortification symbols are not converted into invented named settlements.
- Fort Capuzzo and Fort Maddelena are named sites, **not automatically constructed fortification counters**. [§60.7, n78](https://archive.org/download/campaign-for-north-africa/page/n78.jpg) lists no initial constructed fortifications, minefields or pipeline. Later construction and later-scenario fortification levels are not encoded here.
- Map A index **Benghazi A4827** conflicts with scenario §60.31's **B4827**. The map-feature entry uses the map's A coordinate; the setup file records the discrepancy.
- Map **Amiriya E3312** conflicts with §60.5's **E2212**. Both readings are exposed rather than blending them.
- §60.7's Tobruk initial efficiency wording (7) conflicts with the §55.3 maximum (5) and its stated 3-level initial reduction elsewhere. This file records only the §55.3 maximum; no initial current efficiency is invented.
