# CNA map terrain: conservative initial transcription

## Source and reading convention

Authority: the five original map scans in the [Internet Archive item](https://archive.org/details/campaign-for-north-africa), leaves 187–191. See `map-source.md` for structure, original legend, retrieval evidence, and alternate sources.

This is a **partial best-effort transcription**, not a complete terrain database. Positive entries were read visually from enlarged original scans, not guessed from North African geography or OCR. All other positions are `?`. In particular, `?` means **unresolved**, including an untranscribed or unreadable hex and an unresolved footprint position. It does not prove that a playable hex exists there. Blue background outside an outlined numbered hex is never automatically classified as sea. The bounding grids intentionally preserve these uncertainties.

For each sheet, line `rr` contains one character for each successive printed column `cc`, starting at `01`. Example: character 3 on line `30` of sheet A is **A0330**. Row labels and the separating space are not cells. Even printed columns stagger downward by half a hex; a displayed line is a coordinate row, not a straight horizontal line through all hex centers. The source images must be rotated 90 degrees clockwise for this coordinate-oriented view; it is not north-up.

The main-sheet rectangular envelopes contain unresolved non-grid areas; no rectangular map topology should be inferred. Malta's inset grid is not merged into A's main grid.

## Base-terrain codes

The requested codes contain collisions (`R` rough/road; `C` clear/coast). To preserve unambiguous one-character grids, uppercase codes below denote **base terrain only**. Lowercase codes in the separate feature legend denote overlays. This is a transcription-file convention, not a claim about an engine implementation.

| Code | Base terrain | Original legend |
|---|---|---|
| S | Sea | Sea |
| C | Clear | Clear |
| D | Desert | Desert |
| R | Rough | Rough |
| M | Mountain | Mountain |
| H | Salt marsh | Salt Marsh |
| G | Rock/gravel | Rock/Gravel |
| L | Delta | Delta |
| W | Swamp | Swamp |
| F | Heavy vegetation | Heavy Vegetation |
| ? | Unresolved value or unresolved footprint membership | No assumed terrain |

Codes not present in the grids remain defined because they occur in the original legend. No absence of a terrain type from this partial transcription implies its absence from the board.

## Coverage

The positive readings cover A's initial rock/gravel block and southern desert block; western desert columns of B and C; a small clear/rough block at the start of D and E; and selected outlined sea hexes on A/E. Mixed-color or feature-obscured cells were generally left unresolved. Base clear values do not assert the absence of tracks, wadis, rivers, settlement symbols, or hexside features.

## Interpretation limits

- `?` is deliberately retained rather than making an unsupported clear/desert/sea assignment.
- Bounding-envelope padding and untranscribed cells are not distinguished here; consult the original outlines before creating engine hexes.
- The original scans have folds, overprinted coordinates, transport lines, and partial edge hexes. No terrain was extrapolated across a fold or sheet seam.
- No road network, track network, railroad network, river crossing graph, escarpment adjacency, Malta inset, or named settlement inventory is implied by these base grids.
- The Vassal-module D2228/2328 escarpment correction is reported in `map-source.md`; it is not silently applied to these original-scan grids.
